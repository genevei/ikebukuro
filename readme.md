## What might possibly be the worst repository known to man soon
Ikebukuro will be extension of iso-shinjuku to allow for spaceships other than the glider to be used in syntheses, even enabling the usage of two or more distinct types of spaceship to be used within a single component.
## Line format
orientation+source+timing>spaceship_id-orientation-x-y;spaceship_id2-orientation2-x2-y2;blah-blah-blah>target.

Here x and y are assumed to be the distance from the top-left corner of the source.
